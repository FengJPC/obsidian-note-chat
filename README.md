# 伴读侧栏 / Note Chat — Obsidian 桌面插件

版本 0.1.3，作者 FengJPC。第三方个人项目，不是 OpenAI 或 Obsidian 官方产品。
这是独立的 Obsidian 插件，不会修改已提交审核的 Edge 扩展。

## 安装

1. 下载 `note-chat-sidebar-0.1.3.zip` 并解压，得到 `note-chat-sidebar` 文件夹。
2. 在目标笔记库中打开设置 → 第三方插件 → 打开插件文件夹。或手动打开该库的 `.obsidian/plugins/`；目录不存在时可自行创建。
3. 将整个 `note-chat-sidebar` 文件夹复制进去。最终结构必须是 `.obsidian/plugins/note-chat-sidebar/manifest.json` 和 `main.js`，不要额外套一层目录。旁边的 `ui.html`、`ui.js`、`ui.css`、`katex.css` 等文件也要保留，不能只复制 main.js。
4. 重启 Obsidian，或关闭并重新开启第三方插件。关闭“受限模式”，在已安装插件列表中启用“伴读侧栏 · Note Chat”。
5. 点击左侧聊天图标；或按 Ctrl+P，运行“伴读侧栏：打开伴读侧栏”。视图在右侧打开，也可按 Obsidian 常规方式调整位置。

每个笔记库需要分别安装、启用一次。同一安装包可以复制到多个库，不是每次打开都重装。
本版为桌面插件，主要面向 Windows；最低 Obsidian 1.7.2。手机版不支持。无需另装 Node.js、辅助程序或打开 Codex。
不要将本包当作 Edge 扩展 ZIP 上传。第一版暂未提交 Obsidian 社区插件目录。

## 登录与第一次使用

1. 点击侧栏右上角齿轮 → Continue with ChatGPT。
2. 插件在本机 `127.0.0.1` 的随机空闲端口临时监听授权回调，然后打开系统默认浏览器。亲自完成 OpenAI 官方登录和授权；不要把密码、验证码或回调地址发给其他人。
3. 浏览器显示“已收到授权，请返回 Obsidian”时，回到侧栏。账号身份签名和权限仍须验证成功才会显示“账号已连接”。
4. 点击“刷新模型”，选择当前账号提供的模型，再发送一句测试问题。
5. 如果不想继续登录，点击“取消登录”；默认等待最多 10 分钟后停止。监听器在成功、拒绝、取消或插件关闭后退出，只绑定本机回环地址。

正常使用自己的账号和已授权的 ChatGPT 套餐额度；模型、思考强度、可用权限、预览资格和额度由服务端决定。没有 API Key 输入项，不读取 Edge、Codex 或 ChatGPT 官网 Cookie。当前账号断开后，可以连接另一个账号；不同时共享或池化多个账号令牌。
授权凭据使用本机系统加密，并按库路径区分，存于 Windows `%LOCALAPPDATA%/NoteChatObsidian/`，不存入笔记库。Windows 使用当前用户 DPAPI；可用时优先 Electron safeStorage。其他桌面平台需运行环境提供可靠加密，否则拒绝明文保存并提示。
换电脑、移动笔记库路径或删除本机授权文件后，需要重新登录。把库同步出去不会同步登录。断开清除本库的登录令牌，保留应用登记供下次连接；服务端撤销请在 ChatGPT 设置操作。

## 应用登记复用（0.1.1 起）

修复断开后重新登录重复创建应用登记的问题。已有 0.1.0 登录会自动补存登记信息，不需要为升级重新授权。
设置中的「连接已登记账号」默认复用已有登记；只在连接另一账号或工作区且没有对应登记时，选择「连接其他账号/工作区（新登记）」。所选登记和实际登录身份不符时拒绝保存，不会悄悄新建。
本机各库共用的只有不含令牌的应用登记（client ID、账号身份和显示名称），保存在库外授权目录的 `registrations/`。每个库的登录令牌、账号选择、聊天和设置仍独立；新库必须自行登录授权，不会借用其他库的令牌。不同库同时更新不同登记不会互相覆盖。
断开、重启和重新启用插件不会丢掉登记。已撤销的登记不会被自动替换，清除本机登记目录或换电脑则可能需要新登记；已经存在于服务端的重复条目无法通过本地修复合并。

## 笔记、选文和附件

- 普通聊天不会读取当前笔记，不自动扫描整个库。
- 在 Markdown 的编辑/实时预览/阅读视图，或 PDF 可选中的文本中选中文字 → 右键“发送到伴读侧栏（草稿）”；编辑模式也可运行“将选文放入聊天草稿”命令。选文可编辑，不自动发送。
- “读当前笔记/PDF”按钮将最后打开的 Markdown 笔记或 PDF 加入可移除的资料草稿，发送时才交给 OpenAI。优先取编辑器中的当前文字，包含尚未写盘的编辑。
- 也可以明确说“读一下当前笔记”再发送；插件会按这条指令附上当前笔记。包含“不要读”“如何”“能不能”等询问或否定的句子不会自动读取。
- 文件列表右键一篇 Markdown 笔记或 PDF → “添加到伴读侧栏（草稿）”。第一版不提供跨库搜索或自动改写/删除工具。
- 可粘贴图片、拖入或上传 PNG/JPG/WebP、PDF、MD/TXT/CSV/JSON/TeX/HTML/XML/YAML/LOG 文件；每次最多 3 份、单份最多 20 MB。图片最长边缩放至 2048 px。PDF 本地提取文本，最多 60 页/120000 字符，无 OCR；不执行上传文件。
- 可渲染 Markdown 和 LaTeX，支持行内 `\(...\)`、`$...$` 及显示公式；导出转换为 Obsidian 的 `$...$` 和 `$$...$$`。

阅读视图和 PDF 不需要切到编辑模式。0.1.2 补齐了阅读视图/PDF 选文右键入口，并在打开菜单时保存选文，菜单点击不会因为失去焦点而丢失文字。选中文字时菜单提供“复制”和“发送到伴读侧栏（草稿）”；未选中文字的右键菜单不拦截。弹出独立窗口也会注册入口。PDF 中的扫描图片没有可选文本时，请上传文件或图片；第一版仍不提供 OCR。

0.1.3 修复多标签页下阅读视图/PDF 选文菜单缺失：遍历已打开视图的回调不再返回数组长度，避免被 Obsidian 当作提前结束的信号。

## 历史与保存

- 每个库独立保存对话、草稿、主题、字号、语言和选定模型，不与 Edge 或 ChatGPT 官网历史同步。
- 左上角打开历史；可搜索、重命名、删除和撤销删除。未发送的空白会话不列入历史，草稿仍保留。
- 设置里的“保存对话为 Markdown”、历史条目的“导出 MD”，会在当前库的 `AI 对话/` 内创建文件。插件设置页可以修改目录。
- 同名导出自动加后缀，不覆盖已有笔记。不会自动打开导出文件并抢走当前笔记。
- 导出含对话文字、公式和生成文件名称；图片和原始附件不嵌入 MD，也不包含登录令牌。需要完整附件时自行保留源文件。
- 明确要求“生成一个 md 文件”等时，才启用模型的文本文件工具。生成文件先留在回答里，点击附件后才保存到库；不能执行系统命令、生成二进制 Word/PDF，不能自动写入其他笔记。
- 支持停止生成、3 分钟无进展和 15 分钟总时限。中断或错误不会自动重发；切换模型和强度需等当前回答结束或先停止。

默认跟随系统明暗，可切白天/夜间；字号 12–20 px；简体中文/English；模型支持时可选思考强度；生成文本单文件上限可选 1–5 MB。

## 备份与卸载

聊天和设置在当前库 `.obsidian/plugins/note-chat-sidebar/data.json`。该文件包含可能敏感的对话和资料，备份时按个人数据保护；某些同步工具会同步隐藏目录，因此请检查自己的同步规则。
导出的普通 Markdown 可以由你选择整理备份到 pCloud，插件不自动上传。
更新时先备份 data.json，再替换安装包中的程序文件，不删除 data.json。卸载插件通常移除其目录；导出到普通目录的笔记保留。本机授权文件可先通过“断开”清除。

## 验证范围

本包进行了模拟官方请求下的自动测试，包括真实本机回调监听、回调校验、令牌签名校验、系统凭据加密、独立历史、文本导出保护，以及 Chromium 中的实际侧栏、公式、附件和工具对话。
0.1.3 还在真实 Obsidian 1.14.4 的独立测试库中验证了多标签页阅读视图和 PDF：选中文字后右键显示菜单，点击后保存对应文件的选文草稿，不发起模型请求。没有使用你的笔记、真实账号或登录令牌。
自动测试不等于已完成真实 OpenAI 登录验收。请安装后按上述步骤完成第一次手动登录与聊天。如出错，提供侧栏提示即可，不要发送密码、令牌或完整回调 URL。

## 开发与许可

构建：Node.js 22+，`npm ci` → `npm run build` → `npm test` → `npm run package`。运行用户无需开发环境。

从本仓库获取源码后，按上述顺序构建；安装包位于 `dist/note-chat-sidebar-0.1.3.zip`。GitHub 的源码 ZIP 不能直接作为插件安装，请先构建。

`npm run test:ui` 使用本机 Edge 运行模拟账号的界面测试。可选的 `npm run test:obsidian` 使用独立测试库，需要 Windows 本机已安装 Obsidian 1.14.4，并通过环境变量 `OBSIDIAN_EXECUTABLE_PATH` 指定可执行文件。

构建产物、测试截图、备份、聊天数据和本机账号配置不提交到仓库。`src/ui/pdf-assets.json` 由构建脚本自动生成。
主要逻辑复用 FengJPC 的 Edge 侧栏项目，Obsidian 宿主、桌面登录和库内导出为独立适配。
