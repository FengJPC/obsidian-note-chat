# 伴读侧栏 / Note Chat — Obsidian 桌面插件

版本 0.3.0，作者 FengJPC。第三方个人项目，不是 OpenAI 或 Obsidian 官方产品。
这是独立的 Obsidian 插件，不会修改已提交审核的 Edge 扩展。

## 安装

1. 下载 `note-chat-sidebar-0.3.0.zip` 并解压，得到 `note-chat-sidebar` 文件夹。
2. 在目标笔记库中打开设置 → 第三方插件 → 打开插件文件夹。或手动打开该库的 `.obsidian/plugins/`；目录不存在时可自行创建。
3. 将整个 `note-chat-sidebar` 文件夹复制进去。最终结构必须是 `.obsidian/plugins/note-chat-sidebar/manifest.json` 和 `main.js`，不要额外套一层目录。旁边的 `ui.html`、`ui.js`、`ui.css`、`katex.css` 等文件也要保留，不能只复制 main.js。
4. 重启 Obsidian，或关闭并重新开启第三方插件。关闭“受限模式”，在已安装插件列表中启用“伴读侧栏 · Note Chat”。
5. 点击左侧聊天图标；或按 Ctrl+P，运行“伴读侧栏：打开伴读侧栏”。视图在右侧打开，也可按 Obsidian 常规方式调整位置。

每个笔记库需要分别安装、启用一次。同一安装包可以复制到多个库，不是每次打开都重装。
本版为桌面插件，主要面向 Windows；最低 Obsidian 1.7.2。手机版不支持。无需另装 Node.js、辅助程序或打开 Codex。
不要将本包当作 Edge 扩展 ZIP 上传。第一版暂未提交 Obsidian 社区插件目录。

## 登录与第一次使用

1. 点击侧栏右上角齿轮 → Continue with ChatGPT。
2. 插件在本机 `127.0.0.1` 的随机空闲端口临时监听授权回调，然后打开系统默认浏览器。亲自完成 OpenAI 官方登录和授权；不要把密码、验证码或回调地址发给其他人。
3. 浏览器显示“已收到授权，请返回 Obsidian”时，回到侧栏。账号身份签名和权限仍须验证成功才会显示“账号已连接”。
4. 点击“刷新模型”，选择当前账号提供的模型，再发送一句测试问题。
5. 如果不想继续登录，点击“取消登录”；默认等待最多 10 分钟后停止。监听器在成功、拒绝、取消或插件关闭后退出，只绑定本机回环地址。

正常使用自己的账号和已授权的 ChatGPT 套餐额度；模型、思考强度、可用权限、预览资格和额度由服务端决定。没有 API Key 输入项，不读取 Edge、Codex 或 ChatGPT 官网 Cookie。当前账号断开后，可以连接另一个账号；不同时共享或池化多个账号令牌。
授权凭据使用本机系统加密，并按库路径区分，存于 Windows `%LOCALAPPDATA%/NoteChatObsidian/`，不存入笔记库。Windows 使用当前用户 DPAPI；可用时优先 Electron safeStorage。其他桌面平台需运行环境提供可靠加密，否则拒绝明文保存并提示。
换电脑、移动笔记库路径或删除本机授权文件后，需要重新登录。把库同步出去不会同步登录。断开清除本库的登录令牌，保留应用登记供下次连接；服务端撤销请在 ChatGPT 设置操作。

## 应用登记复用（0.1.1 起）

修复断开后重新登录重复创建应用登记的问题。已有 0.1.0 登录会自动补存登记信息，不需要为升级重新授权。
设置中的「连接已登记账号」默认复用已有登记；只在连接另一账号或工作区且没有对应登记时，选择「连接其他账号/工作区（新登记）」。所选登记和实际登录身份不符时拒绝保存，不会悄悄新建。
本机各库共用的只有不含令牌的应用登记（client ID、账号身份和显示名称），保存在库外授权目录的 `registrations/`。每个库的登录令牌、账号选择、聊天和设置仍独立；新库必须自行登录授权，不会借用其他库的令牌。不同库同时更新不同登记不会互相覆盖。
断开、重启和重新启用插件不会丢掉登记。已撤销的登记不会被自动替换，清除本机登记目录或换电脑则可能需要新登记；已经存在于服务端的重复条目无法通过本地修复合并。

## 笔记、选文和附件

- 普通聊天不会读取当前笔记，不自动扫描整个库。
- 在 Markdown 的编辑/实时预览/阅读视图，或 PDF 可选中的文本中选中文字 → 右键“发送到伴读侧栏（草稿）”；编辑模式也可运行“将选文放入聊天草稿”命令。选文可编辑，不自动发送。
- “读当前笔记/PDF”按钮将最后打开的 Markdown 笔记或 PDF 加入可移除的资料草稿，发送时才交给 OpenAI。优先取编辑器中的当前文字，包含尚未写盘的编辑。
- 也可以明确说“读一下当前笔记”再发送；插件会按这条指令附上当前笔记。包含“不要读”“如何”“能不能”等询问或否定的句子不会自动读取。
- 文件列表右键一篇 Markdown 笔记或 PDF → “添加到伴读侧栏（草稿）”。第一版不提供跨库搜索或自动改写/删除工具。
- 可粘贴图片、拖入或上传 PNG/JPG/WebP、PDF、MD/TXT/CSV/JSON/TeX/HTML/XML/YAML/LOG 文件；每次最多 3 份、单份最多 20 MB。图片最长边缩放至 2048 px。PDF 本地提取文本，最多 60 页/120000 字符，无 OCR；不执行上传文件。
- 可渲染 Markdown 和 LaTeX，支持行内 `\(...\)`、`$...$` 及显示公式；导出转换为 Obsidian 的 `$...$` 和 `$$...$$`。

阅读视图和 PDF 不需要切到编辑模式。0.1.2 补齐了阅读视图/PDF 选文右键入口，并在打开菜单时保存选文，菜单点击不会因为失去焦点而丢失文字。选中文字时菜单提供“复制”和“发送到伴读侧栏（草稿）”；未选中文字的右键菜单不拦截。弹出独立窗口也会注册入口。PDF 中的扫描图片没有可选文本时，请上传文件或图片；第一版仍不提供 OCR。

0.1.3 修复多标签页下阅读视图/PDF 选文菜单缺失：遍历已打开视图的回调不再返回数组长度，避免被 Obsidian 当作提前结束的信号。

## 联网搜索与公共网页/PDF 读取（0.2.0）

输入框上方的「联网：关/开」默认关闭。开启后提供 OpenAI 托管的搜索工具，模型可以按需搜索、打开和查找公共网页；是否可用取决于账号、模型及服务端策略。搜索参数与引用结构参照 [OpenAI Web search 文档](https://developers.openai.com/api/docs/guides/tools-web-search)。不支持时显示原因，不自动重试或改用其他模型。

回答中的引用可以点击，来源列表默认折叠。复制回答、重开历史和导出 Markdown 会保留引用；来源列表也进入 Markdown。工具完成不代表网页内容有效，空结果、错误页和仅有摘要的情况应如实说明。

设置 →「增强公共读取」→ 勾选「允许模型直接读取公共网页和 PDF」，再打开联网，即可按需读取公共 HTTPS 正文。可直接提问「阅读 https://example.com/paper.pdf 并总结」。公共网址不会触发读取无关的当前笔记；本地笔记仍通过原按钮或明确指令添加。

- 直接下载由 Obsidian 宿主执行，和账号请求分离；不带 Cookie、Authorization 或 Referer，不执行网页脚本、不登录、不绕过验证码、不自动跟随跳转。
- 系统 DNS 的实际结果必须为公网地址，并固定到该次连接。遇到 198.18.0.0/15 代理映射地址时，使用 Cloudflare 加密 DNS 查询目标域名的 IPv4 地址，再进行同样检查；解析失败不会放宽地址限制。解析器能看到域名与请求网络地址，不能看到网址路径、聊天或登录凭据。
- HTML/纯文本最多 2 MB，PDF 最多 20 MB；下载和解析有 30 秒时限。PDF 最多提取 60 页/120000 字符，无 OCR。支持静态正文、网页已有的部分 TeX 公式和最多 20 个公开链接；动态网页和跳转可能需要改用托管搜索或上传文件。
- 每个对话保存最多 8 份、共 480000 个 UTF-16 字符的资料快照。模型可查找关键词、分段续读，重复读取默认使用快照。可以查看、导出 TXT 或清空；清空不会抹除已发送的聊天上下文。
- 单次回答最多 12 个模型轮次、24 次增强工具调用；最后一轮只根据已有资料回答。点击停止会取消在途下载，不再提交读取结果。
- 联网诊断可查看数量、导出和清空，最多 50 次请求/2 MB。日志只保存经过筛选和脱敏的查询、来源与状态信息，不保存完整网页正文。查询和网址仍可能含私人信息，请在分享前检查。

资料快照随对话保存在本库插件的 chat-storage/，诊断和设置保存在 data.json，可能随笔记库一起同步。无需为升级重新登录；更新时保留原 data.json 和 chat-storage/。

## 历史与保存

- 每个库独立保存对话、草稿、主题、字号、语言和选定模型，不与 Edge 或 ChatGPT 官网历史同步。
- 左上角打开历史；可搜索、重命名、删除和撤销删除。未发送的空白会话不列入历史，草稿仍保留。
- 设置里的“保存对话为 Markdown”、历史条目的“导出 MD”，会在当前库的 `AI 对话/` 内创建文件。插件设置页可以修改目录。
- 同名导出自动加后缀，不覆盖已有笔记。不会自动打开导出文件并抢走当前笔记。
- 导出含对话文字、公式、联网引用/来源和生成文件名称；图片和原始附件不嵌入 MD，也不包含登录令牌。需要完整附件时自行保留源文件。
- 明确要求“生成一个 md 文件”等时，才启用模型的文本文件工具。生成文件先留在回答里，点击附件后才保存到库；不能执行系统命令、生成二进制 Word/PDF，不能自动写入其他笔记。
- 支持停止生成、3 分钟无进展和 15 分钟总时限。中断或错误不会自动重发；切换模型和强度需等当前回答结束或先停止。

默认跟随系统明暗，可切白天/夜间；字号 12–20 px；简体中文/English；模型支持时可选思考强度；生成文本单文件上限可选 1–5 MB。

## 备份与卸载

聊天、上下文、附件和正文快照在当前库 `.obsidian/plugins/note-chat-sidebar/chat-storage/`；设置和诊断仍在同目录的 `data.json`。这些文件包含可能敏感的对话和资料，备份时按个人数据保护；某些同步工具会同步隐藏目录，因此请检查自己的同步规则。
导出的普通 Markdown 可以由你选择整理备份到 pCloud，插件不自动上传。
更新时先备份 data.json 和 chat-storage/，再替换安装包中的程序文件，不删除这两项。卸载插件通常移除其目录；导出到普通目录的笔记保留。本机授权文件可先通过“断开”清除。

## 多窗口保存与长对话

- 同一宿主的多个窗口通过会话版本和三方合并保存。只修改草稿的旧窗口不会覆盖新增回答；标题、草稿组和消息/上下文/资料快照组分别比较。
- 两边同时修改同一组内容时，保留原会话并新建“冲突副本”，当前窗口切换到副本继续保存。删除后仍有未保存编辑的窗口也会恢复为副本；不会覆盖删除后新建的会话。
- 空闲且没有本地编辑的窗口接收其他窗口更新，保留自己的当前会话。最近启动的生成不会因新开窗口而被标记中断；超过 15 分钟生成上限及短暂缓冲的未完成记录，会在重新打开时恢复为中断状态。
- 每次模型请求采用 240000 字节的 UTF-8 文本预算，并限制序列化输入约 12 MB。图片按固定权重参与文本预算，实际图片数据也计入传输预算。这是本地保守限制，不是服务端精确 token 上限。
- 超限时按完整问答轮次移除最早上下文，保留工具调用、结果和推理配对。完成提示显示省略轮数，历史记录、引用和资料快照仍保留；不自动生成摘要。本轮自身过大时停止发送并提示缩减资料，发送前的草稿和附件保留。
- 流式文字按动画帧合并刷新；已完成消息保留 DOM，避免每个增量重建全部历史。

开发验证：`npm run test:concurrency` 使用隔离 Edge 中的两个真实页面，模拟模型与存储时序，覆盖旧窗口保存、冲突副本、重开、流式 DOM 稳定和上下文预算。共享逻辑维护方式见 [SHARED.md](SHARED.md)。

## 0.2.1 授权错误恢复

授权错误现在区分登录换码和令牌刷新，显示 HTTP 状态及已知错误码。确认刷新令牌失效时移除不可用凭据，保留已有账号登记与聊天，重新登录复用原登记。未知 HTTP 400、临时服务故障和网络错误不会自动清除连接，也不会自动重放授权请求。

凭据写入、失效清理与断开操作串行执行，防止延迟完成的刷新覆盖或清除新会话。设置中的“导出授权诊断”把最近一次已记录 HTTP 授权错误导出到笔记库，只包含时间、阶段、状态码和已知错误类别；不保存响应正文、账号或令牌。诊断元数据随插件 data.json 保存。

自动化测试使用合成凭据；真实账号的恢复情况仍需重新加载插件后验证。

## 0.3.0 多窗口与聊天存储升级

- 修复侧栏弹出或移动到独立窗口后，界面请求无法到达宿主的问题。
- 对话按文件存储，索引只保留标题、时间、消息数等摘要；草稿保存不再重写其他对话。多窗口仍使用版本与三方合并，冲突保留副本。全文搜索和历史 Markdown 导出继续按需读取正文。
- 首次打开自动迁移旧 data.json 的聊天，逐条核对正文后提交新索引。原始聊天保存在 chat-storage/legacy-backup.json；迁移失败不会删除旧聊天。此备份可能包含后来删除的对话，确认迁移完整后可自行删除备份文件。不要直接降级让旧版写入新存储。
- 流式文字通常每 250 毫秒保存一次，等待期间每 5 秒保存存活信息。关闭窗口会尝试保存并停止；支持 Web Locks 的宿主通过生成锁确认窗口存活，不支持时保守等待 2 分钟。突然断电仍可能损失最近尚未落盘的片段。
- 增强网页读取保留表格列分隔；安装包只包含程序文件，不包含聊天文件或迁移备份。
